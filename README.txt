POOJA BHOSALE PORTFOLIO WEBSITE

HOW TO RUN
1. Extract the MyPortfolio folder.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser, or install the Live Server extension and choose "Open with Live Server".

CUSTOMIZE BEFORE PUBLISHING
- Replace your.email@example.com with your real professional email.
- Replace # in GitHub, LinkedIn, and project links with your actual URLs.
- Add your resume PDF to this folder and name it resume.pdf.
- The profile circle is a placeholder. You can replace it with an image by editing the hero-art section in index.html and the relevant CSS.
- Check that the skills and project descriptions accurately reflect your work.

NOTE
Font Awesome icons and Google Fonts require an internet connection. The website itself is static and does not require PHP or MySQL.
